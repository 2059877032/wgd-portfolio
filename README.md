# 王果典 Personal Portfolio

这是明亮清新绿版本的个人 Portfolio 网站。

## 本地预览

当前预览地址：

```text
http://127.0.0.1:8788/
```

也可以直接打开 `index.html`。

如果要重新启动本地服务：

```powershell
cd C:\Users\20598\Documents\ChatGPT\个人简历网站
python -m http.server 8788
```

如果电脑没有安装 Python，可以用任意静态网站服务器打开这个文件夹。

## 部署

这是纯静态网站，可以部署到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 或任意静态托管服务。

需要上传这些内容：

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
